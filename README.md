# お小遣い家計簿 V3.2.8.4.5 — Galaxy / Android PWA 公開版

このリポジトリは「お小遣い家計簿 V3.2.8.4.5」のPWA公開用です。

公開サーバーへ置くのはアプリ本体だけで、実際の支出・残高・カード未払いなどのユーザーデータは端末内（IndexedDB / LocalStorage）に保存されます。

## 普段の使い方

ホーム画面 → お小遣い家計簿 → ＋支出

## 正式利用前の1件テスト

1. 100円のテスト支出を登録
2. 履歴へ出ることを確認
3. 分析へ反映されることを確認
4. テスト支出を削除
5. JSONバックアップが保存できることを確認

## 重要

- 実際の家計データやバックアップJSONはリポジトリへ追加しないでください。
- 更新前にはJSONバックアップを保存してください。
- Chromeのサイトデータ削除や端末初期化で端末内データが失われる可能性があります。


## V3.2.8.4.5 クレカ管理

- 楽天銀行・ゆうちょなどの銀行残高は管理しません。
- クレカ購入は支出と未払いに反映します。
- 財布・家の現金から実際に銀行へ補填した額は「クレカ用確保」として記録します。
- カード支払い時は未払いを減らし、確保済み分を消化します。
- 旧バージョンの銀行口座・履歴は移行時に非表示化して保持します。
- データモデル変更に伴い schemaVersion は 12 です。


## V3.2.8.4.5 履歴の編集・削除ルール

- 支出・資金移動・電子マネーチャージ・外部資金補填・手動のクレカ用確保・カード支払いは、整合性上問題がない場合に編集・削除できます。
- クレカ支出と同時に自動作成されたクレカ用確保、および確保資金返却は「連動」と表示し、直接編集・削除せず元の取引から変更します。
- 返金、残高調整、負債調整は直接の金額編集を行わず、必要に応じて削除後に再登録・再調整します。
- 手動のクレカ用確保は、必要額より多めの丸い金額でも登録できます。超過分は「今月のクレカ端数」として同じ月の次のクレカ利用に使います。
- 今月のクレカ端数は翌月1日に自動リセットし、銀行残高へ吸収されたものとして翌月には繰り越しません。未払いに対応している確保額はリセットしません。
- 既存V3.2.8.4.4以前のデータは破壊的変更せず、そのまま読み込みます。schemaVersionは12を維持します。

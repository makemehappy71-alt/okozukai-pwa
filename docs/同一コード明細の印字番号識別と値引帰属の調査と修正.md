# 同一コード明細の印字番号識別と値引帰属の調査と修正（第11段階）

日付: 2026-11-07 / ブランチ: `codex/receipt-ocr-improvement`
基準: `ac3b518fbe88ff0505d8a0bf335746511a54dda9`

同じ商品コード・数量・元価格の複数明細を、追加の明示的な印字情報で区別できるか検証した。新しい実画像はなく、今回の再現は人工OCR文字列と模擬workerによるもの。実店舗にこの形式があることや、実画像での認識率向上を確認したものではない。
テスト中の緑茶・商品コード・価格は仮の組合せであり、店舗辞書や商品対応は追加していない。

## 再現した問題

| 入力・経路 | 基準版の結果 |
| --- | --- |
| 独立した「明細番号 101」「明細No. 101」 | 101円の商品として誤抽出する |
| 同一コード・数量1・元価格1000円、異なる明細番号101/102、商品値引100円/200円 | 明細番号を保持しないため、物理的な明細を区別できない |
| 「明細番号 102 値引 ¥200」のような明示参照 | 参照先の明細と対応付けられない |
| 明細番号101、クーポン50円、支払51円、商品価格なし | 番号101を元価格候補にして、商品価格を復元する経路がある |
| 同じ番号行の座標、クーポン50円、支払51円 | 番号を商品価格の再OCR用アンカーにする |

通常の商品抽出だけでなく、元価格復元と座標からの商品行選択にも、番号行を商品にしない保護を追加した。実際の「緑茶 ¥101」は引き続き商品価格のアンカーになることも確認した。

## 識別と帰属の条件

対応するラベルは行頭の `明細番号`、`明細No.`（ピリオド省略可）、`明細ID` に限定する。番号は1〜999999の整数で、全角表記を正規化する。先頭ゼロは同じ番号と扱うため、101と000101は別の明細を識別する根拠にならない。
一般的な `No.101`、取引番号、会員番号は商品ごとの番号として利用しない。数字のOCR誤読も補完しない。

番号だけの行は、その直後にある商品名行に結び付ける。商品名に続く既存のコード・数量・価格行にもその番号を保持する。間に別の文字列がある場合や、番号が欠ける場合は補完せず、連番・出現順・残った番号から新しい番号を作らない。
コードだけで商品名が読めない場合は、番号があっても商品名要確認のままにする。番号を商品名へ流用しない。

値引は次の明示根拠で照合する。

- 番号付き商品に直結した既存の「商品値引」「単品値引」等。
- `明細番号 102 値引 ¥200` のように、番号と値引が同じ行にある明示参照。離れた商品や後から出る商品も、一意の参照先があれば対応できる。

商品コード（コードなしなら商品名）・数量・元価格に加えて明細番号の一致を必須にする。同じ番号を持つ別明細、番号の不正・重複、存在しない参照先、認識元間で矛盾する値引対応は自動確定しない。
同一性が衝突する番号付き明細と番号なし明細を、順番だけで結合しない。別名で一意に区別できる商品まで番号を要求することはしない。

以前からの点数・値引合計・小計・税額・支払額の照合も必要で、番号だけで会計の不一致を回避できない。別OCRパスの値引を足し合わせない。
識別できない場合は値引の確認警告を表示し、自動確認・商品別の自動分割を停止する。利用者が商品名だけを確認しても、値引の帰属不足は解消したと扱わない。

確認画面には、読み取れた明細番号を商品コードとともに表示する。`receiptLineId` は解析中の明細だけに保持し、保存用の分割計画や取引へ新しい項目として追加しない。

ブラウザには412pxの2ケースを追加した。

## 保護範囲と残存問題

- schemaVersion 12、app.js、IndexedDB/LocalStorageの保存処理・キー、学習辞書、Service Worker、公開バージョンを維持する。実データは開かず、仮データだけで検証した。
- mainと公開中のGitHub Pagesは変更せず、指定作業ブランチだけへ反映する。無関係なZIPとテスト成果物はコミットしない。
- 同一コード・数量・価格で有効な一意の番号が読めない複数明細は、引き続き自動確定しない。部分OCRや番号付き/番号なしの混在も手動確認になる場合がある。
- 対応する配置は、商品直前の独立した番号行と、番号を先頭に付けた値引参照行に限定する。商品と番号が同じ行、商品後の番号、英数字ID、色・ロット・製造番号等からの識別は未対応で、推測しない。
- 新しい実画像と実店舗の印字形式を検証していない。番号のOCR認識率、Android実機の速度・カメラ・メモリ・操作性は未検証。

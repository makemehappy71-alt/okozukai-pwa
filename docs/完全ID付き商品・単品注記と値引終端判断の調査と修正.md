# 完全ID付き商品・単品注記と値引終端判断の調査と修正（第37段階）

日付: 2026-11-08 / ブランチ: `codex/receipt-ocr-improvement`
基準: `e34fc98a9698cc7470985fd37bb37f55e0ea409c`

人工OCR文字列・模擬worker・隔離ブラウザの仮データで検証した。実画像・実店舗書式・Android実機からの再現ではない。テスト用の商品・コード・金額を学習辞書へ追加しない。

## 再現した問題

第36段階は、単価と商品計の間の「商品」「単品」だけでは対象・適用範囲が確認できないため保留を維持した。今回は、同じ位置の注記に元から完全な明細IDが併記され、折り返し商品IDおよび直後の完全な個別値引参照IDと印字が一致する場合を調べた。

```text
緑茶 (明細ID 00
0100)
2200083271771 1 ¥1,000
(明細ID 000100) 値引
¥100
緑茶 (明細ID 00
0200)
単価 ¥500
商品 (明細ID 000200)
2200083271771 ¥1,000
(明細ID 000200) 値引
¥200
小計 3点 ¥1700
合計 ¥1700
楽天ペイ ¥1700
```

注記は「商品」という範囲表示と明示された完全IDだけで、単価・コード付き商品計の間に1行だけある。元の商品IDから独立した値引参照までの範囲が固定され、注記の完全IDも同じ商品を明示する。単価500円と商品計1000円から数量2を厳密に検証できるが、現行版ではこの行を許容せず保留になった。商品計→単価の順や、注記語と完全IDの前後順が逆の場合も再現した。

従来の商品抽出ではID付きの注記を商品行として扱うことがある。新しい処理はその行を無条件に消すのではなく、次の限定条件を満たす価格項目間の範囲表示としてのみ扱う。

## 修正と安全条件

- 対象は、先頭ゼロ付き数字IDを折り返した商品で、数量の印字がないコード付き商品計と明示単価がある場合だけ。元の商品IDの直後から、元から完全な個別値引参照IDの直前までの範囲を必要とする。
- 価格2項目の間に1行だけある「商品／単品＋括弧付き完全な明細ID」、またはその逆順を `receiptQuantityScopeMarker` で確認する。注記語自体の対応した括弧、水平空白、既存のNFKCを許容する。
- IDは明示された `明細ID` と括弧で閉じた先頭ゼロ付き数字2〜6桁に限定する。元の折り返しID・注記ID・値引参照IDの印字を、ゼロの桁数まで一致させる。数値化後に同じという理由で異なる印字を採用しない。修復したIDや他の認識元のIDを借用しない。
- 同じ認識元の会計境界より前で、その正規化IDを持つ完全な印字の出現は、注記1件と独立した値引参照1件の計2件だけでなければならない。注記・商品・値引参照の追加重複を照合の補強には使わない。既存の折り返し商品/参照の重複検査も維持する。
- ID付き注記だけを復元の証拠にしない。従来どおり、同じ認識元の元から完全な個別値引参照と、独立した値引額終端の根拠を必要とする。注記と別の場所にある裸の値引ラベル・金額を推測で結び付けない。
- 空行か、この厳密なID付き注記のどちらか1行だけを価格項目間で許容する。両方を読み飛ばしたり、商品ID/参照IDとの境界の行を飛ばしたりしない。複数行注記・余分な価格/数量・「税込」「税抜」等の条件文・不一致括弧・余分なID・不明制御文字を除去しない。
- 同じ `receiptOmittedQuantityDetail` により、10〜14桁の元の数字コード、限定した単価書式、正の金額と既存上限、商品計÷単価が1〜99の整数となる条件を検証する。印字数量の上書き、既定値の数量1、点数・総額・辞書による不足補完は行わない。
- 裸の値引額の局所的な円単位、ID/金額の衝突、税・数量・会計・認識元間の矛盾検査、末尾の根拠が無効になった場合の依存する前の判定の取り消しを維持する。
- 書き換えは解析用コピーだけ。コード価格行の元の金額・税区分を残して数量を検証し、注記を新しい商品として数えない。原文の注記・ID・改行・順序と呼出元オブジェクトを保持し、一時的な根拠を保存形式へ追加しない。

第36段階のIDなしの注記を保留する条件は変更しない。新しい認識元の結合・OCR画像処理・OCR呼び出しは追加していない。

## 残存条件と保護範囲

- 厳密な注記・括弧付き完全ID・元の独立した値引参照が不足する場合や、重複・矛盾がある場合は保留。IDなし注記や追加の価格条件を自動対応の対象にしていない。
- 同一行の注記から数量や単価を推測せず、対象外のID種別・書式・離れた価格項目を救済しない。根拠不足の場合は手動確認を残す。
- 実店舗の原画像・位置情報・認識率、Android実機のカメラ・速度・メモリ・操作性は未検証。性能同等性回帰は実機速度の測定ではない。
- app.js、保存処理・キー、schemaVersion 12、学習辞書、Service Worker、公開バージョンは変更しない。main・公開中のGitHub Pages・無関係なZIPは変更対象外。

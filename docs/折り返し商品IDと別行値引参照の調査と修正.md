# 折り返し商品IDと別行値引参照の調査と修正（第31段階）

## 再現した問題

第30段階は、商品側の先頭ゼロ付き数字IDを復元する根拠として、元の個別値引参照にID・ラベル・金額が1行でそろうことを必要としていた。完全な参照IDが元の印字に残っていても、ラベルと金額が別行だと対象外になる。

```text
緑茶 (明細ID 00
0100)
2200083271771 1 ¥1,000
緑茶 (明細ID 00
0200)
2200083271771 1 ¥1,000
(明細ID 000100)
値引
¥100
(明細ID 000200)
値引額（円）
200
小計 2点 ¥1700
合計 ¥1700
楽天ペイ ¥1700
```

IDが完全に印字されていることと、金額の役割が印字で決まることを別々に検査すれば、この例は商品ID同士を相互に推定せずに対応を決められる。元から完全な参照IDがない場合や、裸の数字の役割が不明な場合は区別して保留する。

## 修正と安全条件

`receiptCompleteDiscountContinuation` で、元の1行に完全な括弧付きIDがある参照だけを読み、その直後の既存の注記・ラベル・金額の連続行を検査する。元の値と行位置を一時的に保持する。ID自体が折り返された参照を新しい根拠にしない。

商品側の先頭ゼロ付き数字IDに使える新しい参照は、以下をすべて必要とする。

- 同じ元の認識結果に、完全な参照IDがある。NFKC後の `000100` という元の表記が、商品側の連結値とゼロの桁数まで一致する。`100`・`0100`・`00100` から元の桁数を推定しない。
- 既存の限定書式で値引ラベルと金額を読める。通貨付きの独立金額行、または「値引額（円）」等のその参照の円単位で金額の役割が確定する数字行を扱う。既存の商品/単品注記に続く、同じ行のラベル・金額も既存の解釈を使う。
- 裸の数字行は、その値引参照の円単位が必要。別の参照や共通見出しの単位を借用しない。元の商品情報から単位の不足を補わない。
- 金額直後が次の明示的なID参照、既知の次商品、または会計行の境界である。認識領域の切れ目、未知注記・単位・条件、隣り合う複数の数字候補を参照の完了とみなさない。
- 正規化IDに対する元の個別値引参照が1件だけである。既存の同一行参照と新しい別行参照を別の出現として数え、複数参照から選択・合算しない。商品側の重複・空白による別表記の競合も引き続き保留する。

独立に確認できた元の参照を使って、商品IDと値引参照を解析用コピー内で対応させる。復元後に、価格付き商品が正規化IDごとに1件だけで、無効なIDを含まないことを再検査する。
裸の数字額には、ID復元後も元のまま残るコード・明示数量・通貨付き価格の行を、既存の厳密な書式で確認する。整数単価と数量・価格の一致、全額以上の値引を保留する条件、元の金額終端も維持する。IDの証拠は元の完全な参照であり、復元後の文字列だけをIDの証拠にしない。

不適切な候補は商品IDと付随する参照の両方を採用せず、残りの候補を再検査する。点数・小計・税・値引・支払額・認識元間の帰属一致も既存の会計検査で確認する。IDや合計と同じ値の数字を対象商品に付け替える処理は追加しない。

完全なIDが元にない両側折り返し、裸の数字額に円単位がない場合、元のゼロの桁数違い、未知ID・重複・会計不一致は保留する。新しい商品ID復元の根拠を追加する対象は、先頭ゼロ付きの数字IDだけ。数字IDの1〜6桁・正の値、括弧・断片・タブ・空行の制限、O/0等を補修しない条件、既存の正規化は変更しない。

原文のゼロ・括弧・ラベル・通貨表記・タブ・改行と呼出元オブジェクトを保持する。解析用の付随参照情報は一時的なものとし、商品行・保存用計画・取引・学習辞書に項目を追加しない。

## 残存条件と保護範囲

- 元の完全な参照IDと、金額の役割が独立に確定する印字が同じ認識元にない場合は手動確認を残す。IDの両側折り返しや、裸の数字額に局所的な円単位がない場合を推定しない。
- ゼロの桁数違い・重複ID/参照・空白違い・会計不一致・認識元間の矛盾も保留する。
- 金額終端が不明な認識領域、金額後の未知注記、次の折り返し商品しか境界を示す情報がないケースも、新しい参照根拠として自動採用しない。
- 実店舗書式・画像からの認識率、Android実機のカメラ/速度/メモリ/操作性は未検証。
- app.js、保存処理・キー、schemaVersion 12、学習辞書、Service Worker、公開バージョンは変更しない。実ユーザーデータは開かない。
- 作業ブランチだけへ反映し、main・公開中のGitHub Pages・無関係なZIP・Git管理対象外のテスト成果物は変更対象外。
